Agent Session Sync는 사용자가 고른 Codex·Claude 프로젝트와 세션 파일을 확인 가능한 스냅샷으로 묶어 Google Drive에 보관하는 도구입니다.

현재 상태

실험 단계

개인 Windows 환경에서 제한된 합성·검증 경로를 확인했습니다.

완전 자동 동기화와 Orca·두 대 PC 간 동작은 아직 검증하지 않았습니다.

세 단계

선택하고, 확인하고, 복원합니다.

01

범위 선택

사용자가 승인한 프로젝트와 세션 파일만 allowlist로 지정합니다. 전체 폴더를 자동 수집하지 않습니다.

02

스냅샷 확인

쓰기 작업이 멈춘 대상에서 파일 목록과 해시를 대조합니다. 두 번의 읽기 일치만으로 실행 중 작업의 일관성을 보장하지 않습니다.

03

안전한 복원

Drive에서 내려받은 모든 파일과 해시를 먼저 검증하고, 비어 있는 새 staging 위치에만 복원합니다.

알아둘 점

현재 도구의 경계

사용자 승인 범위

대화 내용과 비밀이 포함될 수 있는 프로젝트·세션 파일을 사용자가 직접 선택합니다. 선택된 스냅샷은 Google Drive로 전송됩니다.

최소 Drive 권한

drive.file 권한으로 앱이 만들었거나 사용자가 명시적으로 승인한 파일을 읽고, 업데이트하고, 생성하고, 삭제합니다. 사용자의 전체 Drive를 읽는 권한이 아닙니다.

검증되지 않은 영역

완전 자동 동기화, Orca 연동, 두 대 PC 간 세션 호환성, 모든 provider의 native resume은 지원한다고 주장하지 않습니다.
