무엇을 처리하나요?

Agent Session Sync는 개인 Windows 환경의 Codex·Claude 작업에서 사용자가 승인한 프로젝트와 세션 파일을 스냅샷으로 처리합니다. 해당 파일에는 대화 내용, 작업 기록, 비밀 정보가 포함될 수 있습니다.

선택된 스냅샷은 Google Drive로 전송될 수 있습니다. 앱이 만든 불변 버전은 사용자가 삭제할 때까지 남을 수 있습니다.

Google Drive와 권한

Google Drive 연결은 drive.file 범위를 사용합니다. 이 범위는 앱이 만든 파일 또는 사용자가 명시적으로 승인한 파일을 읽고, 업데이트하고, 생성하고, 삭제하는 데 필요한 권한이며, 전체 Drive를 읽는 권한이 아닙니다.

Google 계정 설정에서 앱 연결을 취소할 수 있습니다. 이미 저장된 Drive 스냅샷은 연결 취소만으로 삭제되지 않으므로 Google Drive에서 별도로 삭제해야 합니다.

자격 증명과 로컬 기록

OAuth access token과 refresh token은 각 PC의 DPAPI 보호 로컬 저장소에 남으며 스냅샷에 포함하지 않고 동기화하지 않습니다. 로컬에는 파일 처리 상태와 해시 같은 최소 메타데이터가 남을 수 있습니다.

이 웹사이트

이 페이지는 정적 안내 페이지입니다. JavaScript, 쿠키, 분석 도구, 입력 폼, 제3자 리소스를 사용하지 않습니다. 공개 게시 승인 후 GitHub Pages로 제공할 예정입니다. 호스팅 제공자는 요청 IP와 접근·보안 메타데이터를 처리할 수 있으며, 자세한 내용은 GitHub 개인정보처리방침을 따릅니다. 페이지 자체는 파일을 수집하지 않습니다.
